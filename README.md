# Built Panel

Docker-based web hosting control panel: one isolated container stack per customer, managed across multiple Linux servers.

- **Backend:** Rust (Axum, Tokio, SQLx/PostgreSQL, Redis, Bollard)
- **Frontend:** React + TypeScript + Vite
- **Node agent:** Rust, mTLS, typed operations only

Planning, architecture and the task roadmap live in [docs/](docs/README.md). Start with [docs/02-roadmap/README.md](docs/02-roadmap/README.md).
